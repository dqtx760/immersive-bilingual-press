# 插件回归检查

需要 Node.js、可导入的 Playwright 和已安装的 Chrome。测试依赖仅用于本地验收，不参与扩展运行；可以通过 `NODE_PATH` 复用已有的 Playwright 安装。

```powershell
node --test --test-timeout=15000 tests/*.test.cjs
```

使用 Edge 时，在当前终端设置浏览器通道：

```powershell
$env:PLAYWRIGHT_CHANNEL = 'msedge'
```

可选的 `LAYOUT_SCREENSHOT_DIR` 用于指定截图输出目录。测试使用本地页面和模拟的扩展消息、存储及翻译结果，检查真实浏览器中的网页排版、精简弹窗、独立设置页、跨页面配置同步、API 草稿、显示模式、保存失败、快捷键入口、多语言说明和个人资料。后台测试验证 Google 与云端 API 的路由、流式响应和原生快捷键分发，不会调用在线翻译服务。

界面回归还检查收窄弹窗的多语言溢出、四个设置分类的固定外框与内部滚动，以及地址导航、刷新和前进后退。个人资料按指定链接顺序核对，公众号图片须左对齐且不裁切。

悬浮球回归使用真实鼠标与键盘事件，检查小圆形的尺寸、拖动与点击区分、抓取偏移、视口边缘、窗口缩小、取消拖动及设置切换后的状态。

这些检查不代表已验证具体网站的登录页面、网页框架更新行为或真实引擎的翻译质量。
